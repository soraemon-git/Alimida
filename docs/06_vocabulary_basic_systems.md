# 基本体系語彙 v1.1

## 1. 目的

この文書は、Alimida における最初のまとまった **基本体系語彙** を定義する。

基本体系語彙とは、単独の中心語として覚えるより、体系としてまとめて覚えた方がよい語彙群を指す。

```text
1. 数字
2. 方向・位置
3. 色
4. 数量・程度
5. 時間・日付の基礎
```

これらの語彙は [コア語彙 100+](./04_vocabulary_core100.md) とは分けて管理する。コア語彙は、文法上重要な語と優先度の高い中心概念を扱う。

### 3.3 合成規則

```text
11 = deka una
20 = dula deka
21 = dula deka una
100 = sento
200 = dula sento
1000 = kilo
2000 = dula kilo
```

例:

```text
35 = tela deka pema
99 = nona deka nona
125 = sento dula deka pema
256 = dula sento pema deka sika
2026 = dula kilo dula deka sika
```

合成数字はスペースで区切って表記する。

```text
標準:
dula deka una

非標準:
duladekauna
```

9999 を超える大きな数、序数、正式な日付表記、時刻表記は延期する。

### 3.4 数量表現

数字は名詞の前に置く。

```text
数字 + 名詞
```

例:

```text
dula buko
2冊の本

deka una humo
11人
```

### 3.5 数字と `le`

具体的な数がある場合、`le` は通常使わない。

```text
標準:
dula buko

非標準:
dula buko le
```

`le` は、具体的な数を示さず、複数であることだけを示す場合に使う。

```text
buko le
本たち / 複数の本
```

### 3.6 例文

```text
dula buko na nava.
2冊の本は新しい。

deka una humo in tomo.
11人が家にいる。

kono dula nava buko na meli.
この2冊の新しい本は良い。
```

## 4. 方向・位置

### 4.1 設計方針

状態: 採用。

方向・位置語彙は、短く、規則的で、既存の関係語と組み合わせやすい語形にする。

初期品詞方針:

```text
上 / 下 / 前 / 後ろ / 左 / 右 / 外 / 間 / 側 = 位置名詞
近い / 遠い = 性質語
```

位置名詞のために新しい空間関係マーカーは導入しない。位置句の外側で既存の関係語を使う。

```text
側 / そば
```

```text
北

独立名詞としての「内側」

下面
中心
```

### 4.4 位置句の構造

標準形:

```text
参照名詞 + 位置名詞
```

形の例:

```text
tomo feni
家の前 / 家前
```

関係語は位置句の外側に置く。

```text
A in 参照位置.
A はその位置にいる / ある。

A golo to 参照位置.
A はその位置へ行く。

A kita fo 参照位置.
A はその位置から来る。
```

空間位置を表すために `de` は使わない。`de` は所有・所属のみを表す。

### 4.5 関係語: `to` / `in` / `fo`

```text
in = 場所 / そこで
to = 到達点 / 方向 / 対象
fo = 起点 / 由来
```

例:

```text
mi in tomo feni.
私は家の前にいる。

mi golo to tomo feni.
私は家の前へ行く。

mi kita fo tomo feni.
私は家の前から来る。
```

### 4.6 例文

```text
meka in tomo baku.
機械は家の後ろにある。

yu golo to data sida.
あなたはデータの側へ行く。

kono buko na nelo.
この本は近い。

ano tomo na fawa.
あの家は遠い。
```

### 4.7 延期事項

方向・位置語彙の初期セットは、v1.1 の正式仕様として扱う。

以下は v1.1 では採用せず、後の拡張で検討する。

- 北 / 南 / 東 / 西
- 独立名詞としての「内側」
- 表面 / 上面
- 下面
- 中心
- 周囲

## 5. 色

### 5.1 設計方針

状態: 採用。

色語は性質語とする。既存の性質語の文法に従う。

```text
色語 + 名詞
名詞 + na + 色語
```

`blue`, `green`, `white`, `black`, `red` のように Alimida の音韻に合わない英語綴りは避ける。また、`aka`, `ao`, `kuro`, `shiro` のような日本語だけに透明な語根も避ける。

### 5.2 基本セット

第一段階で扱う色:

```text
白
黒
赤
青
緑
黄
```

追加で扱う色:

```text
灰色
茶色
オレンジ
紫
ピンク
```

### 5.4 性質語としての使い方

色語は名詞の前に置いて名詞を修飾する。

```text

```

```text
buko na ledo.
本は赤い。
```

### 5.5 例文

```text

赤い本は良い。

buko na bulu.
本は青い。

wita meka weno to data.
白い機械がデータに接続する。
```

### 5.6 補足

色語彙の初期セットは、v1.1 の正式仕様として扱う。

## 6. 数量・程度

### 6.1 設計方針

状態: 採用。

数量・程度語は、既存語を再定義しない。

```text
ali = すべて / みんな
mida = 誰か / ある人
mo = も / また
zeno = ゼロ
le = 複数
```

`zeno` は正確な数としてのゼロに使う。v1.1 では、「ない」「存在しない」「所有していない」を表す一般的な否定表現としては扱わない。

### 6.2 基本セット

第一段階で扱う意味:

```text
多い / 多くの
少ない / 少しの
いくつかの
数量0
より多い
より少ない
とても
少し / わずかに
十分な
```

### 6.3 語彙表

| 意味 | Alimida | 読み | 品詞 | 状態 | メモ |
|---|---|---|---|---|---|
| 多い / 多くの | muta | ムタ | 数量語 | 採用 | 多さを表す数量語。 |
| 少ない / 少しの | fewa | フェワ | 数量語 | 採用 | 少なさを表す数量語。 |
| いくつかの | soma | ソマ | 数量語 | 採用 | 不定量を表す数量語。 |
| 数量0 | zeno | ゼノ | 数字語 | 採用 | 数量0を表す数字語。存在否定・所有否定・「ない」の一般表現には使わない。 |
| より多い | masa | マサ | 数量語 / 程度語 | 採用 | 比較量を表す語。 |
| より少ない | lesa | レサ | 数量語 / 程度語 | 採用 | 少なさの比較を表す語。 |
| とても | hano | ハノ | 程度語 | 採用 | 強い程度を表す語。 |
| 少し / わずかに | lili | リリ | 程度語 | 採用 | 小さな程度を表す語。 |
| 十分な | safi | サフィ | 数量語 / 程度語 | 採用 | 十分さを表す語。 |

### 6.4 文法メモ

数量語は名詞の前に置く。

```text
数量語 + 名詞
```

程度語は性質語の前に置く。

```text
程度語 + 性質語
```

v1.1 では、程度語は性質語を修飾する語として採用する。程度語が動作句全体を修飾する用法は、v1.1 では正式採用しない。

`zeno` を含め、正確な数がある場合は `le` を使わない。

```text
標準:
zeno buko

非標準:
zeno buko le
```

### 6.5 例文

```text
muta buko in tomo.
多くの本が家にある。

fewa humo in tomo.
少ない人が家にいる。

soma buko na nava.
いくつかの本は新しい。

zeno buko in tomo.
0冊の本が家にある。

hano bano meka weno to data.
とても大きい機械がデータに接続する。

lili weka meka weno to data.
少し弱い機械がデータに接続する。
```

### 6.6 延期事項

数量・程度語彙の初期セットは、v1.1 の正式仕様として扱う。

以下は後の拡張で検討する。

- 動作句全体を修飾する程度語の用法
- 存在否定・所有否定・「ない」の正式表現

## 7. 時間・日付の基礎

### 7.1 設計方針

状態: 採用。

時間・日付の基礎では、まず語彙を導入する。完全なカレンダー表記と時刻表記は延期する。

既存語を尊重する。

```text
tima = いつ
temo = 時 / 時間
mona = 朝
noka = 夜 / 暗い時間
ta = 過去
fu = 未来
dan = その時 / それなら
```

これらの意味と衝突する新語は作らない。

### 7.2 既存の関連語

|---|---|---|---|
| tima | いつ | 採用 | 疑問詞。 |
| temo | 時 / 時間 | 採用 | 名詞。 |
| mona | 朝 | 採用 | 既存コア語。 |
| noka | 夜 / 暗い時間 | 採用 | 既存コア語。 |
| ta | 過去 | 採用 | 時制マーカー。 |
| fu | 未来 | 採用 | 時制マーカー。 |
| dan | その時 / それなら | 採用 | 順序・接続を表す語。 |

### 7.5 文法メモ

時間語は文頭に置いて、文全体の時間文脈を示せる。

```text
時間語 + 文
```

例:

```text
kodeyo mi sena koda.
今日、私はコードを学ぶ。

fudeyo mi fu pako buko.
明日、私は本を作る予定だ。
```

具体的な日付形式と時刻形式は、後の拡張で扱う。

`befa` と `afa` は関係的時間語であり、新しい文法マーカーではない。詳細な句構造は後の拡張で扱う。

### 7.6 例文

```text
kodeyo mi sena koda.
今日、私はコードを学ぶ。

fudeyo yu fu golo to tomo.
明日、あなたは家へ行く予定だ。

tadeyo lu ta kita fo tomo.
昨日、その人は家から来た。

tano mi pako teto.
今、私は文を作る。

eli mona mi golo to tomo.
早い朝、私は家へ行く。
```
