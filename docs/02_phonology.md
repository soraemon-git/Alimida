# Phonology / Pronunciation v0.1

## 1. 目的

この文書は、AI時代の学習用人工言語における発音・表記ルールの最新仕様を定義する。

本言語では、英語のような不規則な読み方を避け、文字と発音の対応ができるだけ一貫した、学習しやすい音声体系を目指す。

## 2. 基本方針

```text
すべての文字は、常に同じ音で読む。
英語のような不規則読み、黙字、母音変化は使用しない。
```

- アルファベット表記を使用する。
- 1文字につき、原則1つの音を対応させる。
- 英語読みを前提にしない。
- 黙字を作らない。
- 初学者でも発音を予測しやすくする。
- 日本語話者に限定せず、国際的に発音しやすい音を優先する。
- AIによる読み上げ・発音チェック・添削と相性の良い仕様にする。

例:

```text
a は常に「ア」に近い音として読む。
i は常に「イ」に近い音として読む。
u は常に「ウ」に近い音として読む。
e は常に「エ」に近い音として読む。
o は常に「オ」に近い音として読む。
```

`name` を英語のように「ネイム」と読むことはない。本言語では `na-me` のように、書かれた文字通りに読む。

## 3. 使用文字

v0.1では、以下の20文字を使用する。

```text
a b d e f g h i k l m n o p s t u w y z
```

### 3.1 母音

```text
a i u e o
```

| 文字 | 発音イメージ | 備考 |
|---|---|---|
| a | ア | 常に「ア」に近い音 |
| i | イ | 常に「イ」に近い音 |
| u | ウ | 常に「ウ」に近い音 |
| e | エ | 常に「エ」に近い音 |
| o | オ | 常に「オ」に近い音 |

母音は固定された音で読む。英語のように、`a` を「エイ」「ア」「オ」などと読み分けることはない。

### 3.2 子音

```text
b d f g h k l m n p s t w y z
```

| 文字 | 発音イメージ | 備考 |
|---|---|---|
| p | パ行系 | `pa`, `pi`, `pu`, `pe`, `po` |
| b | バ行系 | `ba`, `bi`, `bu`, `be`, `bo` |
| t | タ行系 | `ta`, `ti`, `tu`, `te`, `to` |
| d | ダ行系 | `da`, `di`, `du`, `de`, `do` |
| k | カ行系 | `ka`, `ki`, `ku`, `ke`, `ko` |
| g | ガ行系 | `ga`, `gi`, `gu`, `ge`, `go` |
| m | マ行系 | `ma`, `mi`, `mu`, `me`, `mo` |
| n | ナ行系 | `na`, `ni`, `nu`, `ne`, `no` |
| s | サ行系 | `sa`, `si`, `su`, `se`, `so` |
| z | ザ行系 | `za`, `zi`, `zu`, `ze`, `zo` |
| h | ハ行系 | `ha`, `hi`, `hu`, `he`, `ho` |
| f | ファ行系 | `fa`, `fi`, `fu`, `fe`, `fo` |
| l | ラ行系 | `la`, `li`, `lu`, `le`, `lo` |
| w | ワ行系 | `wa`, `wi`, `wu`, `we`, `wo` |
| y | ヤ行系 | `ya`, `yi`, `yu`, `ye`, `yo` |

## 4. 使用しない文字

v0.1では、以下の文字は使用しない。

```text
c j q r v x
```

| 文字 | 使用しない理由 |
|---|---|
| c | 言語によって `k`, `s`, `ch` など読みが変わりやすい |
| j | 英語・フランス語・スペイン語・ドイツ語などで読みが大きく異なる |
| q | 使用頻度が低く、他の文字で代替可能 |
| r | `l` との区別が難しい話者が多いため、v0.1では不採用 |
| v | `b` や `f` と混同しやすい話者が多いため、v0.1では不採用 |
| x | `ks`, `z`, `sh` など読みが不安定になりやすい |

## 5. 長母音

v0.1では、長母音を独立した音として扱わない。

```text
aa = a-a
```

自然な会話の中で長く聞こえる程度の揺れは許容するが、長さの違いによって単語の意味を区別しない。

## 6. `l` の扱い

v0.1では、`r` と `l` を区別しない。表記上は `l` に統一する。

```text
l = ラ行系の音
```

英語の `l` のように厳密に発音する必要はない。日本語話者がラ行に近い音で発音してもよい。

```text
r と l の違いで単語の意味を区別しない。
表記には r を使わず、l のみを使う。
```

例:

```text
luma
```

標準的には「ルマ」に近く読む。

## 7. `y` の扱い

`y` はヤ行系の音として使用する。

| 表記 | 発音イメージ |
|---|---|
| ya | ヤ |
| yi | イに近いヤ行音 |
| yu | ユ |
| ye | イェ |
| yo | ヨ |

`yi` と `i`、`ye` と `e` の区別が難しい場合があるため、語彙設計では多用しない。

## 8. `w` の扱い

`w` はワ行系の音として使用する。

| 表記 | 発音イメージ |
|---|---|
| wa | ワ |
| wi | ウィ |
| wu | ウ |
| we | ウェ |
| wo | ウォ |

`wu` と `u` の区別が弱くなる可能性があるため、語彙設計では多用しない。

## 9. 音節構造

発音しやすさを優先し、音節構造をシンプルにする。

### 9.1 基本音節

```text
V
CV
CVn
```

| 形 | 例 | 説明 |
|---|---|---|
| V | `a`, `i`, `o` | 母音のみ |
| CV | `ma`, `lo`, `ki` | 子音 + 母音 |
| CVn | `lan`, `ton`, `sen` | 子音 + 母音 + n |

### 9.2 原則として避ける音節

| 形 | 例 | 方針 |
|---|---|---|
| CCV | `tra`, `pla`, `ski` | 使用しない |
| CVC | `tok`, `mes`, `lat` | 原則使用しない。ただし `n` 終わりのみ許可 |
| CCCV | `stra`, `spre` | 使用しない |

## 10. 単語末の音

単語は原則として母音で終わる。

```text
malo
sena
temo
luma
pako
```

ただし、`n` のみ単語末子音として許可する。

```text
lan
sen
ton
```

単語末 `n` は、短い機能語、文法マーカー、接続要素、特に短くしたい基本語、語感上母音終わりより自然な語に限定して使用する。基本語彙では母音終わりを優先する。

## 11. 二重母音

v0.1では、二重母音を独立した音として扱わない。以下のような並びは、原則として母音を分けて読む。

```text
ai = a-i
au = a-u
ei = e-i
ou = o-u
```

例:

```text
mai
```

標準的には `ma-i` と読む。ただし、自然な会話の中で「マイ」に近くなる程度の揺れは許容する。意味の区別には使用しない。

## 12. アクセント

v0.1では、アクセントによって単語の意味を区別しない。

標準的な読み方としては、後ろから2番目の音節にアクセントを置くことを推奨する。

```text
luma = LU-ma
sena = SE-na
temo = TE-mo
langa = LAN-ga
pakona = pa-KO-na
```

アクセントが異なっても意味は変わらない。母語によるアクセントの揺れは許容する。

## 13. 禁止する発音ルール

v0.1では、以下を禁止する。

```text
英語読み
黙字
不規則発音
文字ごとの複数読み
r/l の意味上の区別
子音連続
母音の曖昧化
アクセントによる意味区別
```

例:

```text
mi = ミ
na = ナ
luma = ルマ
```

`mi` を「マイ」、`na` を「ネイ」、`luma` を「ルーマ」と読むことは標準としない。

## 14. 表記ルール

### 14.1 小文字

通常の単語は小文字で表記する。

```text
mi sena koda.
```

### 14.2 大文字

大文字は、固有名詞、文の強調、見出し、UI表示、学習教材上の強調に使用してもよい。大文字と小文字で単語の意味は変わらない。

```text
mi = Mi = MI
```

### 14.3 句読点

| 記号 | 用途 |
|---|---|
| `.` | 文の終わり |
| `?` | 疑問文 |
| `,` | 文中の区切り |
| `!` | 強調、感嘆 |

例:

```text
ka yu sena koda?
```
