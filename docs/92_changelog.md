### メモ

- `bi` は v1.1 では行為者・手段を表す語とし、原因全般には広げない
- `fo` は v1.1 では起点・由来を表す語とし、原因表現への拡張は今後検討する
- `no` は返答語であり、文中否定には使用しない
- 文中否定には `nu` を使用する
- `mi no sena koda.` は v1.1 以降、非標準とする
- 普通の目的語には `to` を付けない
- `to` は日本語の「に」「へ」ではなく、動作が向かう先を示す到達点マーカーとして扱う
- 関係語を伴う疑問詞の語順は今後検討する
- `tima` は疑問詞「いつ」、`temo` は名詞「時・時間」として区別する
- `homa` と `humo` は人に関わる語として意味的に関連するが、疑問詞と名詞で品詞を分ける
- `yume` は日本語由来語としてではなく、Alimida の語感に合う抽象語として扱う
- 許容形は誤りとは言わず、標準形を併記する
- 非標準形は v1.1 では修正対象とする
- 標準形では関係語と疑問詞をセットで文頭に置く
- 関係語句を元の位置に置く形は許容形とする
- 関係語を省略した疑問詞文頭形は、文脈または動詞構文型から関係が明確な場合のみ会話許容とする
- 性質語は、名詞の前では形容詞的に、動詞句の後ろでは副詞的に、`na` の後ろでは述語的に働く
- 数字語は `zeno / una / dula / tela / fola / pema / sika / sepa / oka / nona / deka / sento / kilo`
- `zeno` は数量0を表す数字語であり、存在否定・所有否定・「ない」の一般表現には使わない
- `peta` は SI 接頭辞との混同を避けるため採用せず、5 は `pema` とする
- 合成数字はスペース区切りで表記する
- 序数・日付・時刻は今後検討する
