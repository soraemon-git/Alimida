# 教材用標準例文100本

状態: v1.2 教材用

この文書は、教材・レッスン・単語帳・AI添削テストで使いやすい標準例文100本を整理する。ここに含める `EX-001` 〜 `EX-100` は、原則として標準形の完全な文のみとする。

許容形・会話許容形・非標準形・よくある誤りは、[13_practice.md](./13_practice.md) で扱う。

## 既存例文からの流用

この100本には、[05_examples.md](./05_examples.md) の既存例文を多く流用している。流用時には、語彙が v1.1 の採用語であること、文法形が標準形であること、文法項目とレベルが明示できることを確認した。
