# 概要

## 1. 言語名

本言語の名称は **Alimida** とする。  
略式名称は **Alim** とする。

Alimida は、基本語彙である `ali`（すべて・全員）と `mida`（誰か・ある人）をもとにした名称である。

この名前は、「すべての人が学びやすい言語」「誰もが言語の仕組みを理解するための入口」という意味を持つ。

## 2. 目的

このプロジェクトは、AI時代の学習に適した人工言語を設計するための仕様群である。

本言語は、英語の代替そのものではなく、多言語学習の足場として使うことを目的とする。初学者が文構造・品詞・時制・語順を理解しやすくし、AI添削・翻訳比較・発音練習と組み合わせやすい、規則的で説明しやすい言語仕様を目指す。

## 3. 設計思想

- 発音と表記の対応をできるだけ一貫させる。
- 英語読み、黙字、不規則発音を避ける。
- 短く、学習しやすく、AI処理しやすい語彙を優先する。
- 文法マーカーを明示し、初学者が文の構造を分解しやすくする。
- 音声会話では、疑問や時制などの情報が早めに分かる構造を推奨する。
- 日本語話者だけに偏らず、国際的に発音しやすい形を優先する。

## 4. 対象ユースケース

- 初学者向けの文法学習
- 多言語学習の導入教材
- AIによる添削・翻訳比較
- 発音練習と音声読み上げ
- 学習アプリ用の例文・単語帳
- 文法分解や構文可視化の教材

## 5. 語彙方針

語彙の雰囲気は `C + D` とする。

```text
C. 日本語・英語・世界語彙を少し混ぜる
D. AI・未来感のある短い語彙
```

日本語由来語は、日本語話者向けに偏らせるのではなく、言語共通の語彙として活用できそうな語を一部取り入れる。AI・構造・情報系の語彙は、短く、機能的で、やや未来感のある音を優先する。

### 日本語由来語の扱い

Alimida では、日本語由来語を完全には排除しない。ただし、日本語話者だけが意味を連想しやすい一般基礎語を多用することは避ける。

日本語由来語は、以下のいずれかに当てはまる場合に採用候補とする。

1. 海外でも一定の認知がある語
2. 短く、発音しやすく、非日本語話者にも独立語として覚えやすい語
3. Alimida の語感・世界観に合う語
4. 文化語彙・固有性のある語として意図的に採用する語

一方で、`hito`, `mizu`, `sora`, `kage`, `gaku`, `nani`, `doko`, `toki` のように、日本語話者には分かりやすいが、国際的な透明性が低い一般基礎語は見直し対象とする。

ただし、Alimida の語感に合う語は、必ずしも語源にこだわらず採用する。たとえば `yume` は、日本語由来語としてではなく、Alimida の抽象語として語感が合うため維持する。
