# コア語彙 100+α v1.1

## 1. 目的

この文書は、AI時代の学習用人工言語における基本語彙100+αの仕様を定義する。

当初は基本100語を目安としていたが、文法上重要な機能語や学習上有用な語は、必要に応じて追加する。そのため、v1.1 以降は厳密に100語へ固定せず、100+αとして扱う。

本語彙リストは、文法仕様、例文作成、レッスン設計、AI添削機能、学習アプリ用単語帳、翻訳・文法分解機能の検証に使用する。

数字・方向・色・量・時間など、体系としてまとめて覚える基本語彙は、コア語彙 100+α には直接含めず、[06_vocabulary_basic_systems.md](./06_vocabulary_basic_systems.md) で管理する。

## 2. 語彙設計方針

語彙の雰囲気は `C + D` とする。

```text
C. 日本語・英語・世界語彙を少し混ぜる
D. AI・未来感のある短い語彙
```

日本語由来語は、日本語話者向けに偏らせるのではなく、言語共通の語彙として活用できそうな語を一部取り入れる。

## 3. 語彙作成ルール

基本語彙は、発音仕様 v0.1 に従って作成する。

```text
- アルファベット表記を使う
- 母音は a i u e o の5つ
- 1文字1音を基本とする
- 英語読みはしない
- c j q r v x は使用しない
- r/l は区別せず、l に統一する
- 単語は原則として母音で終わる
- n のみ単語末子音として許可する
- 子音連続は原則使用しない
```

語彙は、発音しやすく、綴りから読みを予測しやすく、できるだけ短い形を優先する。日本語由来語を使う場合も、国際的に発音しやすい形に調整する。

品詞体系の扱いは [03_grammar.md](./03_grammar.md) を参照する。各単語の品詞は、この基本語彙表で定義する。

数字語 `zeno / una / dula / tela / fola / pema / sika / sepa / oka / nona / deka / sento / kilo` は基本体系語彙側で管理し、コア語彙 100+α の語数には含めない。
