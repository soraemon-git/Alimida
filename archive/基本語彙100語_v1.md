# 基本語彙100語 v1

## 1. 目的

この文書は、AI時代の学習用人工言語における基本語彙100語の v1 案を定義する。

本語彙リストは、今後の以下の作業のたたき台として使用する。

- 文法仕様の作成
- 例文作成
- レッスン設計
- AI添削機能の設計
- 学習アプリ用の単語帳作成
- 翻訳・文法分解機能の検証

v1時点では、語彙は正式決定ではなく、**検討用の初期候補**とする。

---

## 2. v1での主な変更点

v0.1から、以下を反映する。

```text
- 複数形は le で統一する
- 代名詞・指示語の複数形は派生語として扱い、基本100語には含めない
- 一般名詞の複数は、独立マーカー le で表す
- ko / so / ano を kono / sono / ano に変更する
- yusu は「あなたたち」と衝突し得るため廃止し、「使う」は yuta に変更する
- ka は疑問マーカーとして文法・機能語に含め、疑問詞カテゴリでは重複カウントしない
```

---

## 3. 語彙設計方針

語彙の雰囲気は以下の方針とする。

```text
C + D
```

つまり、以下を組み合わせる。

```text
C. 日本語・英語・世界語彙を少し混ぜる
D. AI・未来感のある短い語彙
```

ただし、Cについては以下のように定義する。

```text
日本語話者向けに偏らせるのではなく、
言語共通の語彙として活用できそうな日本語由来語を一部取り入れる。
```

---

## 4. 語彙作成ルール

基本語彙は、発音仕様 v0.1 に従って作成する。

主なルールは以下の通り。

```text
- アルファベット表記を使う
- 母音は a i u e o の5つ
- 1文字1音を基本とする
- 英語読みはしない
- c j q r v x は使用しない
- r/l は区別せず、l に統一する
- 単語は原則として母音で終わる
- n のみ単語末子音として許可する
- 子音連続は原則使用しない
```

---

## 5. 複数表現

v1では、複数表現に `le` を使用する。

```text
le = 複数を表す要素
```

### 5.1 代名詞・指示語の複数

代名詞・指示語では、`le` は接尾語として結合する。

| 単数 | 複数 | 意味 |
|---|---|---|
| mi | mile | 私たち |
| yu | yule | あなたたち |
| lu | lule | その人たち |
| kono | konole | これら |
| sono | sonole | それら |
| ano | anole | あれら |

これらの複数形は規則的に作れるため、**基本100語には含めない派生語**として扱う。

### 5.2 一般名詞の複数

一般名詞では、`le` は独立した複数マーカーとして名詞の後ろに置く。

| 単数 | 複数 | 意味 |
|---|---|---|
| hito | hito le | 人々 |
| buko | buko le | 複数の本 |
| koda | koda le | 複数のコード |
| meka | meka le | 複数の機械 |

### 5.3 指示語が名詞を修飾する場合

指示語が名詞を修飾する場合は、名詞側の `le` で複数を表すことを基本とする。

```text
kono buko le
これらの本

sono hito le
その人たち

ano meka le
あの機械たち
```

指示語を単独で使う場合は、`le` を接尾語として結合できる。

```text
konole
これら

sonole
それら

anole
あれら
```

# 8. サンプル文

## 8.1 自己紹介

```text
mi na hito.
私は人です。

mi nama Toshi.
私の名前はToshiです。

mi in tomo.
私は家にいます。

mi suki koda.
私はコードが好きです。
```

---

## 8.2 学習

```text
mi sena koda.
私はコードを学ぶ。

yu sena gaku ka?
あなたは学習をしますか？

ka yu selo sima?
あなたは意味を知っていますか？

nani yu sena?
あなたは何を学びますか？
```

## 8.3 AI・未来感のある文

```text

情報はデータの中にある。

案内はあなたを助ける。
```

# 10. 調整候補

## 10.1 `toki` の多義性

`toki` は以下の2つの意味を持つ候補である。

```text
toki = 時間
toki = いつ
```

初期仕様では許容してもよいが、将来的に混乱が出る場合は分離する。

候補：

```text
toki = 時間
kato = いつ
```

---

## 10.2 `no` の多義性

`no` は以下の2つの意味を持つ候補である。

```text
no = 否定
no = いいえ
```

初期仕様では兼用してもよいが、学習教材上の混乱が出る場合は分離する。

候補：

```text
no = 否定
noya = いいえ
```

---

## 10.3 `navi` の品詞兼用

`navi` は名詞と動詞の両方で使用する候補である。

```text
navi = 案内・導き
navi = 案内する・導く
```

初期仕様では兼用してもよいが、品詞体系を厳密にする場合は分離する。

候補：

```text
navi = 案内・導き
navo = 案内する・導く
```

---

## 10.4 日本語由来語の比率

v1では、日本語由来語が比較的多い。

例：

```text

```

# 12. まとめ

基本語彙100語 v1 は、以下の方針に基づく初期候補である。

```text
- 発音仕様 v0.1 に従う
- 短く発音しやすい語を優先する
- 日本語由来語を一部採用する
- ただし日本語話者専用にはしない
- AI・未来感のある語彙を混ぜる
- 初級文法・例文・レッスンで使いやすい語を優先する
- 複数表現は le に統一する
- 代名詞・指示語の複数形は派生語として扱い、基本100語には含めない
- 一般名詞の複数は独立マーカー le で表す
- v1時点では正式決定ではなく、今後調整する
```
