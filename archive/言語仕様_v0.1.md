# 発音仕様 v0.1

## 1. 目的

この文書は、AI時代の学習用人工言語における発音・表記ルールの初期仕様を定義する。

本言語では、英語のような不規則な読み方を避け、**文字と発音の対応ができるだけ一貫した、学習しやすい音声体系**を目指す。

特に以下を重視する。

* アルファベット表記を使用する
* 1文字につき、原則1つの音を対応させる
* 英語読みを前提にしない
* 黙字を作らない
* 初学者でも発音を予測しやすくする
* 日本語話者に限定せず、国際的に発音しやすい音を優先する
* AIによる読み上げ・発音チェック・添削と相性の良い仕様にする

---

## 2. 基本方針

本言語の発音仕様は、以下の方針に従う。

```text
すべての文字は、常に同じ音で読む。
英語のような不規則読み、黙字、母音変化は使用しない。
```

例：

```text
a は常に「ア」に近い音として読む。
i は常に「イ」に近い音として読む。
u は常に「ウ」に近い音として読む。
e は常に「エ」に近い音として読む。
o は常に「オ」に近い音として読む。
```

英語のように、同じ文字が単語によって別の音になることはない。

例：

```text
name
```

この語を英語のように「ネイム」と読むことはない。
本言語では、`na-me` のように、書かれた文字通りに読む。

## 3. 使用文字

v0.1では、以下の20文字を使用する。

```text
a b d e f g h i k l m n o p s t u w y z
```

### 3.1 使用する母音

```text
a i u e o
```

### 3.2 使用する子音

```text
b d f g h k l m n p s t w y z
```

---

## 4. 使用しない文字

v0.1では、以下の文字は使用しない。

```text
c j q r v x
```

### 4.1 使用しない理由

| 文字 | 使用しない理由                            |
| -- | ---------------------------------- |
| c  | 言語によって `k`, `s`, `ch` など読みが変わりやすい  |
| j  | 英語・フランス語・スペイン語・ドイツ語などで読みが大きく異なる    |
| q  | 使用頻度が低く、他の文字で代替可能                  |
| r  | `l` との区別が難しい話者が多いため、v0.1では不採用      |
| v  | `b` や `f` と混同しやすい話者が多いため、v0.1では不採用 |
| x  | `ks`, `z`, `sh` など読みが不安定になりやすい     |

## 5. 母音

母音は5つのみとする。

| 文字 | 発音イメージ | 備考        |
| -- | ------ | --------- |
| a  | ア      | 常に「ア」に近い音 |
| i  | イ      | 常に「イ」に近い音 |
| u  | ウ      | 常に「ウ」に近い音 |
| e  | エ      | 常に「エ」に近い音 |
| o  | オ      | 常に「オ」に近い音 |

### 5.1 母音の基本ルール

母音は、常に固定された音で読む。

```text
a = ア
i = イ
u = ウ
e = エ
o = オ
```

英語のように、`a` を「エイ」「ア」「オ」などと読み分けることはない。

### 5.2 長母音

v0.1では、長母音を独立した音として扱わない。

例：

```text
aa
```

これは「アー」ではなく、原則として `a-a` として読む。

ただし、自然な会話の中で長く聞こえる程度の揺れは許容する。
長さの違いによって単語の意味を区別しない。

## 7. `l` の扱い

v0.1では、`r` と `l` を区別しない。

表記上は `l` に統一する。

```text
l = ラ行系の音
```

ただし、英語の `l` のように厳密に発音する必要はない。
日本語話者がラ行に近い音で発音してもよい。

### 7.1 ルール

```text
r と l の違いで単語の意味を区別しない。
表記には r を使わず、l のみを使う。
```

例：

```text
luma
```

標準的には「ルマ」に近く読む。
英語話者が `l` に近く発音しても、日本語話者がラ行に近く発音してもよい。

---

## 8. `y` の扱い

`y` はヤ行系の音として使用する。

| 表記 | 発音イメージ  |
| -- | ------- |
| ya | ヤ       |
| yi | イに近いヤ行音 |
| yu | ユ       |
| ye | イェ      |
| yo | ヨ       |

v0.1では、`yi` と `i`、`ye` と `e` の区別が難しい場合があるため、語彙設計では多用しない。

## 9. `w` の扱い

`w` はワ行系の音として使用する。

| 表記 | 発音イメージ |
| -- | ------ |
| wa | ワ      |
| wi | ウィ     |
| wu | ウ      |
| we | ウェ     |
| wo | ウォ     |

v0.1では、`wu` と `u` の区別が弱くなる可能性があるため、語彙設計では多用しない。

## 10. 音節構造

v0.1では、発音しやすさを優先し、音節構造をシンプルにする。

### 10.1 基本音節

基本音節は以下とする。

```text
V
CV
CVn
```

| 形   | 例                   | 説明          |
| --- | ------------------- | ----------- |
| V   | `a`, `i`, `o`       | 母音のみ        |
| CV  | `ma`, `lo`, `ki`    | 子音 + 母音     |
| CVn | `lan`, `ton`, `sen` | 子音 + 母音 + n |

### 10.2 原則として避ける音節

v0.1では、以下のような音節は原則として使用しない。

| 形    | 例                   | 方針                      |
| ---- | ------------------- | ----------------------- |
| CCV  | `tra`, `pla`, `ski` | 使用しない                   |
| CVC  | `tok`, `mes`, `lat` | 原則使用しない。ただし `n` 終わりのみ許可 |
| CCCV | `stra`, `spre`      | 使用しない                   |

## 11. 単語末の音

v0.1では、単語は原則として母音で終わる。

```text
malo
sena
toki
luma
pako
```

ただし、`n` のみ単語末子音として許可する。

```text
lan
sen
ton
```

### 11.1 単語末 `n` の用途

単語末の `n` は、以下のような用途に限定して使用する。

* 短い機能語
* 文法マーカー
* 接続要素
* 特に短くしたい基本語
* 語感上、母音終わりより自然な語

ただし、多用しすぎると発音難易度が上がるため、基本語彙では母音終わりを優先する。

---

## 12. 二重母音

v0.1では、二重母音を独立した音として扱わない。

以下のような並びは、原則として母音を分けて読む。

```text
ai = a-i
au = a-u
ei = e-i
ou = o-u
```

例：

```text
mai
```

標準的には `ma-i` と読む。
ただし、自然な会話の中で「マイ」に近くなる程度の揺れは許容する。

意味の区別には使用しない。

---

## 13. アクセント

v0.1では、アクセントによって単語の意味を区別しない。

標準的な読み方としては、以下を推奨する。

```text
アクセントは後ろから2番目の音節に置く。
```

例：

```text
luma  = LU-ma
sena  = SE-na
toki  = TO-ki
langa = LAN-ga
pakona = pa-KO-na
```

ただし、アクセントが異なっても意味は変わらない。
母語によるアクセントの揺れは許容する。

---

## 14. 禁止する発音ルール

v0.1では、以下を禁止する。

```text
英語読み
黙字
不規則発音
文字ごとの複数読み
r/l の意味上の区別
子音連続
母音の曖昧化
アクセントによる意味区別
```

### 14.1 英語読みの禁止

アルファベットを使用するが、英語読みはしない。

例：

```text
mi
```

これは「マイ」ではなく「ミ」と読む。

```text
na
```

これは「ネイ」ではなく「ナ」と読む。

```text
luma
```

これは「ルーマ」ではなく、原則として「ルマ」と読む。

## 15. 語彙設計の方向性

v0.1では、語彙の雰囲気を以下の方針とする。

```text
C + D
```

つまり、

```text
C. 日本語・英語・世界語彙を少し混ぜる
D. AI・未来感のある短い語彙
```

を組み合わせる。

ただし、Cについては以下のように定義する。

```text
日本語話者向けに偏らせるのではなく、
言語共通の語彙として活用できそうな日本語由来語を一部取り入れる。
```

---

## 16. 語彙設計の基本方針

語彙は、以下の基準で作成する。

* 発音しやすい
* 綴りから読みを予測しやすい
* できるだけ短い
* 似た意味の語に音のまとまりを持たせる
* 英語だけに偏らない
* 日本語由来語を使う場合も、国際的に発音しやすい形に調整する
* AI・未来感・学習言語らしさを出す
* ただし、意味が分かりにくすぎる完全ランダム語彙にはしない

---

## 17. 日本語由来語の扱い

日本語由来語を取り入れる場合、そのまま採用するのではなく、本言語の発音ルールに合わせて調整する。

### 17.1 採用しやすい日本語由来語の条件

以下の条件を満たす語は採用候補とする。

* 音が短い
* 母音終わりである
* 子音連続がない
* 国際的にも発音しやすい
* 意味が抽象化しやすい
* 既に海外でもある程度知られている、または音として覚えやすい

### 17.2 採用候補の例

| 元の日本語 | 候補語  | 意味案        | 備考                     |
| ----- | ---- | ---------- | ---------------------- |
| 空     | sora | 空、上方、空間    | 発音しやすい                 |
| 花     | hana | 花、自然、美しいもの | 国際的にも発音しやすい            |
| 水     | mizu | 水、液体       | `z` を含むが許容範囲           |
| 心     | koko | 心、感情、内面    | `kokoro` を短縮           |
| 音     | oto  | 音、声、信号     | 非常に発音しやすい              |
| 道     | mido | 道、方法、プロセス  | `michi` は `ch` を含むため変形 |
| 光     | hika | 光、明るさ      | `hikari` を短縮           |
| 影     | kage | 影、暗さ、背後    | 発音しやすい                 |
| 夢     | yume | 夢、想像、目標    | 発音しやすい                 |
| 時     | toki | 時間、時点      | 発音しやすい                 |

## 21. 表記ルール

### 21.1 小文字を基本とする

通常の単語は小文字で表記する。

```text
mi sena koda.
```

### 21.2 大文字

大文字は以下の場合に使用してもよい。

* 固有名詞
* 文の強調
* 見出し
* UI表示
* 学習教材上の強調

ただし、大文字と小文字で単語の意味は変わらない。

```text
mi = Mi = MI
```

### 21.3 句読点

句読点は、読みやすさのために使用する。

| 記号  | 用途     |
| --- | ------ |
| `.` | 文の終わり  |
| `?` | 疑問文    |
| `,` | 文中の区切り |
| `!` | 強調、感嘆  |

例：

```text
yu sena koda ka?
```

## 24. まとめ

v0.1の発音仕様は、以下のルールを基本とする。

```text
- アルファベット表記を使う
- 使用文字は20文字
- 母音は a i u e o の5つ
- a=ア, i=イ, u=ウ, e=エ, o=オ
- すべての文字は原則1文字1音
- 英語読みはしない
- 黙字は作らない
- c j q r v x は使用しない
- r/l は区別せず、l に統一する
- 単語は原則として母音で終わる
- n のみ単語末子音として許可する
- 子音連続は原則使用しない
- アクセントで意味を区別しない
- 語彙の雰囲気は「日本語由来を含む言語共通語彙」+「AI・未来感のある短い語彙」とする
```
